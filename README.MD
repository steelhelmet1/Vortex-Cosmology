# Vortex Cosmology: Emergent Gravity and Electromagnetism

This repository contains the Python source codes for a two-part computational series investigating the emergence of fundamental forces from the dynamics of vortical solitons in a nonlinear field. 

## Papers
- **Paper I (Gravity):** Emergent Gravity from Vortical Energy Densities: An AI-Assisted Computational Proof of Concept Across Cosmic and Atomic Scales.
- **Paper II (Electromagnetism):** Emergent Electromagnetism from Topological Phase Winding: Charge and Annihilation in a Nonlinear Vortex Field.

## Methodology
These simulations were developed under human scientific direction (conceptualization, methodological design, and critical validation) utilizing AI-assisted coding (Prompt Engineering) to handle the mathematical and computational execution.
